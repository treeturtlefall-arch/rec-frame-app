01 / ORIGIN STORY

「こちらに微笑みかける女の子」と目が合った日

THE ARTISAN'S PERSPECTIVE // INSIGHT

“

AI画像生成をしていた時。こちらに視線を向け、柔らかく微笑みかける女の子の画像が生まれました。

『すごく可愛い。でも、もっと“そこにいるリアリティ”を出せないだろうか？』

ふと思いついたのが、ビデオカメラのファインダーでした。
四隅のL字枠、赤丸のREC表示、緑の電池マーク、そして右下に刻まれた撮影日時。

それらを重ねた瞬間、絵の中に『レンズを構えている撮影者の視線』が生まれました。
ただの生成画像が、まるで『旅先でふと目が合って、思わずシャッターを切った記録写真』のように息づき始めたのです。

02 / CRAFTSMANSHIP

こだわった2つの哲学

単なる画像加工ツールではなく、愛着ある画像への敬意を込めた設計思想。

shield_with_heart

元画像は、絶対に傷つけない。
（非破壊設計）

レトロ感を出すために画像全体を汚す破壊フィルターはかけません。エフェクト（2000sデジカメの色収差やOLEDの微発光）がかかるのは、重ねたUIオーバーレイ層だけ。こだわって生成したイラストや大切な写真は、最高画質のまま残します。

Original Pixels 100% Intact verified
straighten

どんな解像度でも崩れない。
（純粋ベクター相対計算）

透過PNG素材を引き伸ばす安直な手法は使いません。画像の縦横サイズからピクセル単位で相対計算してベクター描画。正方形イラストでもスマホの縦長写真でも、四隅のマージンと線幅は常に美しく揃います。

Dynamic Aspect Ratio Pixel-Perfect crop_free

LOSSLESS BLEND

03 / EFFECTS

3つの質感で、世界観を変える。

3 PRESETS × 3 FONTS // 3X REAL DETAIL
OFF (クリーン) 白枠 × Bahnschrift (工業的)
PRESET 01
REC周辺 3倍拡大 (白枠) SHARP

くっきりした白枠と工業的フォント。一切のにじみを排除し、測定機器や軍用HUDのような硬質で洗練された仕上げに。

FILTER: NONE / SOLID CRISP
OLED (微発光) 黒枠 × Consolas (等幅)
PRESET 02
REC周辺 3倍拡大 (黒枠) BLOOM

黒枠の背後に柔らかく広がる発光オーラ。等幅フォントと相まって、小型端末の液晶ディスプレイを覗いているような温かみ。

FILTER: GAUSSIAN BLOOM
2000s (デジカメ) 白枠 × Arial Narrow Bold (細長)
PRESET 03
REC周辺 3倍拡大 (白枠) RGB SHIFT

わずかな色ずれ（RGBシフト）と低解像化の粗さ。往年のデジカメを彷彿とさせる細長フォントで、平成レトロの質感を再現。

FILTER: CHROMATIC SHIFT
desktop_windows DESKTOP GUI INTERFACE

直感的なデスクトップUI

左でスタイルを選び、右ですぐにプレビュー。簡易モードでシンプルに使うことも、詳細モードで十字や日時の位置・フォント（10種＋カスタム）を細かく詰めることも可能です。

04 / VIBE CODING

「自分のほしい」は、
AIと一緒にここまで作れる。

このアプリはPython標準の tkinter と Pillow だけで作られています。重いフレームワークは一切使わず、単体exeでサクッと動くミニマルな快感。

AIと対話しながら、ピクセル単位の挙動を詰め、テストを書き、パッケージングする。
『こんなのあったらいいな』という思いつきから、手触りの良いデスクトップアプリが数日で形になりました。

次はあなたが、あなたの『ほしい』を形にする番です。
