色・太さ・フォントを選ぶ。Color, bracket weight and font

枠色は黒／白、枠太さは3段階。フォント候補10種に加え、所持フォントも登録できます。赤丸はいつも赤。Black or white, three bracket weights and ten font choices, plus your own fonts. The REC dot stays red.

フォントはOSのものを使い、見つからない場合は代替フォントで描画します。Fonts use your system; unavailable fonts fall back.

日時も、写真に合わせて。A timestamp for each photo

日時部分・2倍拡大 / 2× detail

文字を手入力するか、「写真の撮影日時を使う」を選択。旅行の記録や撮影風の演出に。Enter your own text or use the photo's capture time.

撮影日時がない画像ではファイルの更新時刻を使い、それも取得できない場合は入力した文字を使います。Uses EXIF capture time, then file modification time, then your entered text.

GET STARTED

Pythonからの起動・CLI一括処理 / Python & CLI

Python 3.11以上・Pillow・tkinterを使う開発者向けの例です。環境構築はREADMEへ。For developers using Python 3.11+, Pillow and tkinter. See the README for setup.

.venv\Scripts\python rec_frame_app.py

rem Batch with remembered settings
.venv\Scripts\python rec_frame_app.py --batch input output

rem Batch with a config file and English messages
.venv\Scripts\python rec_frame_app.py --lang en --batch input output --config rec_frame_config.json

Windows版exeも rec-frame-app.exe --batch input output で一括処理できます。The Windows executable also supports CLI batch processing.
